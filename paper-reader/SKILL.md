# PaperReader

Use the supplied paper, PDF, or existing report as the starting point. Deliver one self-contained HTML file per requested paper, edition, and language. An HTML index is optional for a collection.

## Edition and language

Read the [shared report rules](references/report-format.md) and the guide for the requested edition.

- **Full edition (default).** Follow the [full-edition guide](references/full-edition.md) to explain the paper's reasoning, trace the method, and interpret its experiments.
- **Simple edition.** Follow the [simple-edition guide](references/simple-edition.md) for a shorter Motivation and Method with the complete Overview and Evaluation. If a full report exists, use it as the starting point and check it against the paper.
- **Language.** Accept prompts in Chinese or English. Use the requested report language, or follow the language of the prompt when none is specified. If the user requests both languages, produce a matching pair. Use the report language for explanations, captions you write, definition cards, pseudocode comments, and control labels. Keep the paper's original title, identifiers, equations, and quoted figure labels. In Chinese prose, retain established English terms and explain them in Chinese through the definition cards.

Start with the paper's full title, then Overview, Motivation, Method, and Evaluation. Use the reference guides to check source attribution, figures, offline behavior, and actual desktop rendering before delivery.
